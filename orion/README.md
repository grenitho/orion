# Orion - AI Software Engineer Otonom untuk VS Code

Orion adalah ekstensi VS Code yang mengubah cara Anda bekerja dengan AI. Dari sekadar "mengetik kode dan bertanya" menjadi "memberi instruksi tingkat tinggi dan AI mengeksekusinya secara otonom".

## ✨ Fitur Utama
- **Agentic Loop**: Orion bisa berpikir, memanggil tool, dan menyimpulkan secara mandiri.
- **Project Intelligence**: Memahami struktur dan dependensi project Anda secara otomatis.
- **Terminal Safety**: Konfirmasi manual untuk perintah terminal yang berisiko.
- **Self-Correction**: Otomatis memperbaiki error kode atau terminal tanpa perlu disuruh.
- **Rich UI**: Tampilan chat dengan syntax highlighting dan markdown rendering yang rapi.

## 🚀 Cara Menggunakan
1. Buka folder project Anda di VS Code.
2. Tekan `Ctrl+Shift+P` dan ketik `Orion: Open Chat`.
3. Berikan instruksi tingkat tinggi, biarkan Orion yang mengerjakan detailnya!
